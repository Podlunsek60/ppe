# Guide utilisateur — Informations et actualités

Ce guide concerne uniquement la consultation et la gestion des **informations** publiées sur le site PPE. Il ne décrit pas les autres rubriques du site.

Les libellés entre guillemets reprennent les textes visibles dans l’interface. Les fonctions d’administration nécessitent les droits correspondants.

## Consulter les informations

Sur la page d’accueil, le bloc **Dernières nouvelles** présente les publications récentes. Cliquez sur **Voir toutes les informations** pour ouvrir la liste **Toutes les informations**. Dans l’espace membre, le bloc s’appelle **Informations récentes** et le lien **Voir toutes** mène à cette même liste.

Cliquez sur une carte ou sur son lien de lecture pour ouvrir une publication. Sa page de détail peut présenter le texte, des images intégrées, une illustration et des documents PDF. Cliquez sur le nom d’un PDF pour l’ouvrir.

Les informations portant le badge **Privé · membres** sont réservées aux membres connectés. Une publication expirée n’apparaît plus dans les listes visibles.

## Accéder à la gestion des informations

La création et la modification nécessitent le droit **📰 Informations**.

1. Connectez-vous, puis ouvrez **👤 Espace membre**.
2. Dans **Mes fonctions d'administration**, cliquez sur **📰 Informations**.
3. La page **Gestion des informations** affiche la liste **Informations publiées**, avec leur visibilité, leur date de fin, leurs PDF et les actions disponibles.
4. Cliquez sur **Nouvelle information** pour créer une publication.

Si **📰 Informations** n’apparaît pas, le droit n’est probablement pas attribué à votre compte. Contactez un administrateur du site.

## Créer une information

Le formulaire comporte trois étapes : **Essentiel**, **Sujet** et **Facultatif**. Le bouton **Étape suivante** permet de passer d’une étape à la suivante ; les boutons en bas du formulaire permettent de revenir ou de terminer.

### Étape 1 — Essentiel

- Dans **Titre**, saisissez un titre clair, jusqu’à 150 caractères.
- Dans **Qui peut voir cette information ?**, choisissez **Tout le monde** ou **Membres connectés uniquement**.
- Dans **Date de fin**, indiquez le dernier jour où l’information doit rester visible.
- Cliquez sur **Étape suivante**. Le formulaire signale les champs obligatoires manquants.

### Étape 2 — Sujet

1. Rédigez le message dans l’éditeur **Sujet et contenu**.
2. Utilisez la barre d’outils pour mettre en forme le texte, créer une liste, ajouter un lien ou insérer une image.
3. Vérifiez que le contenu comporte du texte ou une image.

Les images insérées sont téléversées depuis l’éditeur. Par défaut, elles ne sont pas ajoutées à la bibliothèque d’illustrations. Cochez **Ajouter les images insérées au texte à la bibliothèque** si vous souhaitez les réutiliser ensuite.

### Étape 3 — Facultatif

L’**Aperçu avant publication** se met à jour pendant la rédaction. Relisez le titre, la visibilité, l’illustration et le contenu avant d’enregistrer.

- **Image ou logo** : choisissez une illustration disponible ou cliquez sur **Téléverser et utiliser l’image**. Les formats acceptés sont JPG, PNG et GIF, jusqu’à 300 Ko.
- **Documents PDF** : sélectionnez un ou plusieurs PDF (20 Mo maximum par fichier). Cliquez sur **Retirer** pour enlever un fichier de la sélection.

Cliquez sur **Enregistrer l’information** pour sauvegarder. Si des PDF ont été sélectionnés, ils sont téléversés après l’enregistrement ; la page **Documents associés à une information** s’ouvre. Attendez la fin des transferts et vérifiez la liste **Documents déjà associés**.

## Modifier une information

1. Dans **Informations publiées**, cliquez sur **Modifier** sur la ligne voulue.
2. Vérifiez le badge **Modification** et le titre affiché.
3. Parcourez les étapes, modifiez les champs nécessaires et cliquez sur **Enregistrer l’information**.
4. Pour gérer des PDF déjà associés, utilisez **Gérer les PDF (nombre)**.

Le bouton **Gérer les PDF (0)** est désactivé quand aucun document n’est associé. Pour ajouter des PDF dans ce cas, modifiez l’information, sélectionnez-les dans **Documents PDF**, puis enregistrez.

## Gérer les illustrations

Le droit **🖼️ Photos** donne accès à la bibliothèque générale depuis **👤 Espace membre** → **Mes fonctions d'administration** → **🖼️ Photos**. La page s’intitule **Images par défaut des actualités** et contient la **Bibliothèque d’images**.

- Pour ajouter une image, utilisez la zone **Ajouter des images à la bibliothèque** ou glissez-déposez le fichier dans cette zone.
- Les formats acceptés sont JPG, JPEG, PNG, WEBP et AVIF ; la taille maximale est de 300 Ko.
- Les images de **Images disponibles** peuvent être réutilisées comme illustration principale.
- Une image encore utilisée par une information ne peut pas être supprimée.

Depuis le formulaire, **Gérer les images par défaut** ouvre la bibliothèque dans un nouvel onglet afin de préserver votre brouillon.

## Supprimer une information

Dans **Informations publiées**, cliquez sur **Supprimer** sur la ligne correspondante et confirmez seulement si vous souhaitez réellement supprimer la publication. La suppression est définitive et retire également les PDF associés.

## Accès et dépannage

- Une information **Privé · membres** nécessite une connexion ; vérifiez également qu’elle n’a pas expiré.
- Si **📰 Informations** ou **🖼️ Photos** n’apparaît pas sous **Mes fonctions d'administration**, demandez à un administrateur de vérifier le droit correspondant.
- Si une image insérée ne figure pas dans **Image ou logo**, c’est normal si l’option **Ajouter les images insérées au texte à la bibliothèque** n’était pas cochée lors de son téléversement.
- Si un PDF n’a pas été joint, vérifiez qu’il est au format PDF et respecte la limite de taille. Réessayez en modifiant l’information, en sélectionnant le fichier dans **Documents PDF**, puis en cliquant sur **Enregistrer l’information**.
- Si **Gérer les PDF (0)** est désactivé, aucun PDF n’est encore associé : ajoutez le fichier depuis le formulaire comme indiqué ci-dessus.

Pour les détails techniques sur le fonctionnement, le stockage et les contrôles du module, consultez la [documentation technique des informations](../information/Index.md).
